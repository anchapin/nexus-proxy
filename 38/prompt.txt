## Your Assigned Focus Area
**`internal/router` + `internal/middleware`** — Routing correctness, DSL/SLM gaps, prompt injection, middleware chain ordering

## Repository Context

**What Nexus Proxy does:** A Go proxy that intercepts OpenAI-compatible `/v1/chat/completions`, applies prompt optimizations (TOON compression, RAG injection, meta-prompting), and routes each request to either a local Ollama model or a frontier API based on complexity heuristics (DSL → SLM fallback → Fusion panel).

**Key packages:**
- `internal/router/` — Guardrail → DSL → SLM.Decide routing pipeline
- `internal/middleware/` — Prompt transforms only (no net/http — unit-testable)

**Routing pipeline:**
1. Guardrail (VRAM/token budget → frontier if oversized)
2. DSL regex fast-pass (formatting → local, architecture → fusion)
3. SLM fallback (qwen3-coder:4b JSON decision, cached)
4. Fusion panel (local + frontier race, arbiter synthesizes on disagreement)

**Key knobs:** `NEXUS_SLM_CACHE_MAX_ENTRIES=512`, `NEXUS_SLM_CONFIDENCE_THRESHOLD=0.3`, `NEXUS_DSL_*_PATTERNS`, `NEXUS_PROMPT_INJECTION_MODE=off`, `NEXUS_MIDDLEWARE_CHAIN`

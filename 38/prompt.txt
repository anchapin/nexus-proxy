func containsWord(s, kw string) bool {
    if kw == "" {

### Proposed solution
Return `false` when `kw == ""` instead of `true`:

func containsWord(s, kw string) bool {
    if kw == "" {
        return false  // empty keyword matches nothing
    }
    // ...
}
```

Add a test case in `dsl_test.go` asserting `containsWord("anything", "") == false` and `Categorize("") != ""`.

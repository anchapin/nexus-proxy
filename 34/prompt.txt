### What `nexus-proxy` Does

Nexus Proxy sits between AI coding agents (OpenCode, Aider, OpenHands) and model providers. It intercepts OpenAI-compatible `/v1/chat/completions` requests, optimizes prompts (TOON compression, RAG injection, meta-prompting), and routes each request to either a local Ollama model or a frontier API based on complexity.

**Key packages**:
- `internal/rag/` — vector store + persistent store + embedders
- `internal/middleware/rag.go` — RAG injection middleware (NO net/http)

**Dependency rule (CRITICAL)**: `internal/handlers` and `internal/upstream` must **never** import `internal/judge` or `internal/quality`

2. **Look for**:
   - `TODO`, `FIXME`, `XXX`, `HACK` comments
   - Unbounded allocations (`io.ReadAll`, no size limits)
   - Silent error swallowing (`_ = err`, missing `return`)
   - Hardcoded values that should be configurable
   - Missing metrics/tracing on hot paths
   - Race conditions (shared mutable state without locks)
   - Dead code (functions called by nothing)
   - Missing graceful shutdown paths
   - Untested error branches

3. **Cross-reference the PRD** for unchecked or partially-done items

4. **Score candidates**:
   - Does it fix a real bug or advance a PRD phase?
   - Can it be completed in 1–2 days?
   - Are acceptance criteria unambiguous and testable?
   - Is it not already filed?

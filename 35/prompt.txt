## Repository Context

**What Nexus Proxy does:** A Go proxy that intercepts OpenAI-compatible `/v1/chat/completions`, applies prompt optimizations (TOON compression, RAG injection, meta-prompting), and routes each request to either a local Ollama model or a frontier API based on complexity heuristics (DSL → SLM fallback → Fusion panel).

**Key packages:**
- `internal/observability/` — Prometheus collector, OTLP tracing
- `internal/tracing/` — W3C trace context + OTLP/JSON exporter
- `internal/metrics/` — SQLite metrics store → savings dashboard

**Key knobs:** `NEXUS_TRACING_ENDPOINT`, `NEXUS_DEBUG=true`, `NEXUS_LOG_LEVEL`, `NEXUS_LOG_FORMAT`

**Prometheus metrics at `/metrics`:**
- `nexus_tracing_dropped_total` — OTLP spans dropped
- `nexus_budget_*` — spend/budget guard counters
- `nexus_health_circuit_*` — Ollama circuit breaker state transitions
- `nexus_rag_circuit_*` — RAG embedder circuit breaker state transitions
- `nexus_upstream_*` — per-route/upstream counters and histograms
